# BetterClipboard

一个基于 **Qt 6 + QML（基于HuskarUI框架） + SQLite** 的本地剪贴板历史管理工具。

自动捕获复制到剪贴板的文本，按类型分类存储到本地数据库，
并通过 QML 界面提供分类浏览、分页查看、最近记录、删除等操作。

---

## ✨ 功能特性

- （实现）📋 **自动捕获剪贴板文本** —— 后台监听剪贴板变化，实时入库
- （实现）🗂 **按类型分类** —— 每条数据带 `type` 字段，支持按类型筛选
- （实现）🕒 **最近数据视图** —— 独立展示最近 N 条记录，跨类型
- （实现）🗑 **删除单条记录** —— 通过自增 `id` 精确定位并删除
- （实现）💾 **本地存储** —— 数据保存在 SQLite 文件中，无需联网
- （实现）🧩 **C++ / QML 分离** —— 业务逻辑在 C++，界面在 QML，通过 `QAbstractListModel` 交互
- 目前app的核心功能均已实现

## ✨ 如何使用？（后续将会推出发行版）

1. 下载源码 || 在你的文件夹中执行`git clone https://github.com/yylwq/BetterClipBoard.git`
2. 执行如下指令（须Qt环境）
``` cmake
mkdir build && cd build
cmake .. && cmake --build .
```
---

## ✨ 如何删除？

- 直接删除文件夹即可
- 注：所有数据都存储在 根目录/data/BetterCB_data.db 中

---

## ✨ 数据迁移

- 所有数据都存储在 根目录/data/BetterCB_data.db 中
- 将该文件复制到 目标目录/data/ 即可
